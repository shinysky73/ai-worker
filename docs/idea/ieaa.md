1. 영수증/명함 사진 →엑셀 자동 변환 서비스	이미지 여러 장 업로드하면 정보 추출해서 정리된 엑셀 파일로 다운로드.	
2. 프레젠테이션 발표스크립트 생성기	슬라이드 이미지들 올리면 각 슬라이드별 발표 스크립트 초안 생성. 발표 시간 예측
3. JD 기반 면접 질문 생성기	채용 공고 입력하면 직무별 예상 면접 질문 + 평가 포인트 생성. HR팀 실무 활용.
4. 업무 인수인계 문서 자동 생성기	담당 업무 설명, 주요 히스토리, 주의사항 입력하면 구조화된 인수인계 문서 생성.
5. 표/차트 이미지 →텍스트 설명 변환기	보고서에 있는 복잡한 표나 차트 이미지 올리면 말로 풀어서 설명. 시각 자료 접근성 향상.
